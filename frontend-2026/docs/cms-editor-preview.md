# Editorial desk — review and production handoff
Open /cms-preview/ on the review host or open public/cms-preview/index.html in a modern browser from the extracted source ZIP. There is no account or server involved. The draft list, Japanese and English variants and optional cover images are stored only in localStorage for that browser/origin. This is a local editorial trial with no publication or applicant data. Drafts are not backed up. Use sample copy.

Review both News and Careers: enter Japanese and English content, save, reload, reopen, preview and return to editing. Click another draft with unsaved changes and check the discard prompt. Inspect job detail fields separately from editorial article fields.
